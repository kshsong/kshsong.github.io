如何使用 Hugo 搭建个人博客

本教程将详细介绍如何使用 Hugo 框架搭建一个现代化的个人博客。

前置要求

在开始之前，请确保你已经安装了：

  • Git
  • Hugo (版本 0.115.0 或更高)

步骤一：创建 Hugo 站点

首先，创建一个新的 Hugo 站点：

hugo new site my-blog
cd my-blog

步骤二：初始化 Git 仓库

git init
git add .
git commit -m "Initial commit"

步骤三：添加主题

本博客使用 Hugo Blox Builder 的 Academic CV 主题：

# 添加主题模块
hugo mod init github.com/username/my-blog

在 config/_default/module.yaml 中配置：

imports:
  - path: github.com/HugoBlox/hugo-blox-builder/starters/academic-cv

步骤四：配置网站

编辑 config/_default/hugo.yaml：

baseURL: 'https://yourusername.github.io'
languageCode: 'zh-cn'
title: '你的博客名称'

步骤五：创建内容

创建第一篇文章：

hugo new post/my-first-post.md

步骤六：本地预览

启动本地服务器：

hugo server -D

访问 http://localhost:1313 查看效果。

步骤七：部署到 GitHub Pages

  1. 在 GitHub 创建仓库 username.github.io
  2. 配置 GitHub Actions 工作流
  3. 推送代码，自动部署

高级配置

启用中文支持

在 config/_default/hugo.yaml 中添加：

hasCJKLanguage: true

自定义样式

在 assets/scss/ 目录下创建自定义样式文件。

总结

Hugo 提供了一个强大而高效的博客搭建解决方案。通过合理配置，你可以建立一个专业且易于维护的个人博客。
