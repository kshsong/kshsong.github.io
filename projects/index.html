代表性科研工作

OH + CH3OH 反应体系：全维高精度势能面与反应动力学研究

采用 Δ-Machine Learning 方法构建全维高精度神经网络解析势能面，节省 90% 的计算成本；通过准经典动力学模拟研究反应速率系数、积分反应截面、微分反应截面及产物能量分配；结合简正模式分析（NMA）与准经典动力学，研究不同振动／转动模式激发条件下的模式特异性反应动力学。

简历标注相关论文：1、3、4、7。

H2COO 振动诱导单分子反应动力学

通过计算构建 H2COO 两个反应通道的 PhysNet 全维高精度解析势能面；通过振动诱导激发开展反应动力学模拟，分析反应动力学行为；揭示振动激发对反应通道及动力学行为的影响，探索人为控制反应过程的可能性。

简历标注相关论文：5。

H2 + NH2− 体系：全维势能面与反应动力学

采用 PIP-NN 构建包含三个反应通道的全维高精度神经网络势能面；通过准经典动力学计算研究夺氢反应速率系数及同位素效应；发现 H2 转动模式激发对反应具有抑制作用，并分析其动力学机制。

简历标注相关论文：8。

科研程序与工具

DML — Δ-Machine Learning 高效采样程序

github.com/kshsong/DML

用于 PIP-NN／FI-NN，利用神经网络的非线性及有限外推能力进行高效采样；自动去除结构相似的数据点，降低高精度电子结构计算成本；支持 OpenMP 并行。

PIPNN-gen — PIP 及对应 Fortran 调用代码自动生成工具

github.com/kshsong/PIPNN-gen

根据指定化学体系自动生成 PIP 及对应 Fortran 调用代码；支持结构筛选及并行去除相似结构。

h3s-fit — 基于 CQPES 的 PIP-NN 势能面构建与模拟示例

github.com/kshsong/h3s-fit

以 H + H2S 体系为例展示 CQPES 与 PIP-NN 势能面构建流程；实现 PIP-NN 势能面训练及调用，并接入 ASE 实现单点能计算、结构优化及频率计算。
